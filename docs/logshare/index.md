# Logshare

Logshare 是一个专为 Minecraft 设计的日志分享与分析平台，重构自 mclo.gs，提供更稳定、更快速的日志上传和分享服务。

## ✨ 核心特性

- 🚀 **快速上传**: 支持多种方式上传日志文件
- 🔗 **永久链接**: 生成短链接便于分享
- 📊 **语法高亮**: 支持 Minecraft 日志语法高亮显示
- 📱 **响应式设计**: 完美适配各种设备
- 🔌 **内置集成**: 已内置到 FCL 和 ZL2 启动器
- 🇨🇳 **国内加速**: 国内用户访问速度快，延迟低

## 📝 关于项目

Logshare 由 **琪初** 负责前后端开发，托管在香港区腾讯云服务器上。该项目为 FCL 和 ZL2 启动器提供内置的日志上传功能，方便玩家快速分享游戏日志。
