## **安装须知**
该插件的源代码全部由cursor-Claude 3.5提供，作者仅仅提供了想法与方向。  
如果你确实需要安装此插件，请**谨慎考虑**！(有必要时对存档进行备份处理)

## 核心要求
- Java 21 或更高版本。
- 必须是spigot及下游，支持1.13 - 1.21版本的paper及分支。

## 下载
你目前可以在以下平台下载最新版本 (v1.4.0-beta.1):
- [Modrinth](https://modrinth.com/plugin/bellcommand)
- [GitHub Releases](https://github.com/ning-g-mo/BellCommand/releases)
- [MineBBS](https://www.minebbs.com/threads/bellcommand.32806/)

## 安装插件
将下载好的 `bellcommand-1.4.0-beta.1.jar` 放入 `plugins` 文件夹内，并重新启动服务器。

## 成功
如果控制台出现以下内容:
```shell
[xx:xx:xx INFO]: [BellCommand] Enabling BellCommand v1.4.0-beta.1
[xx:xx:xx INFO]: [BellCommand] §a已检测到 Floodgate，基岩版支持已启用
[xx:xx:xx INFO]: [BellCommand] §6[BellCommand] 版本: v1.4.0-beta.1
```
恭喜，你成功了！
