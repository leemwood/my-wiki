# v1.4.0-beta.1

这是 v1.4.0 系列的首个 Beta 版本，汇总了所有 Alpha 版本的重大更新。

## 🚀 核心更新
- **配置系统重构**: 模块化多文件夹架构。
- **次数性物品**: 支持多种消耗逻辑。
- **热重载**: `WatchService` 实时同步。
- **稳定性**: 引入 `ReentrantReadWriteLock` 读写锁。
- **自动化**: 深度集成 Modrinth 发布流程。

## 🛠️ 技术改进
- 全面支持 UTF-8 编码。
- 升级至 JDK 21 编译。
- 优化了 Floodgate 玩家交互判定。
