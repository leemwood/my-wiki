# 更新日志

这里记录了 BellCommand 的所有版本变动。

## v1.4.0-beta.2 (2026-01-02)

### 核心特性
- **指令系统全面增强**: 
  - 为主命令 `/bc` 引入了完整的 `TabCompleter` 自动补全支持。
  - 支持 `as-op` 执行模式，允许玩家以管理员权限执行特定物品命令。
  - 扩展了位置占位符，支持 `%world%`, `%x%`, `%y%`, `%z%`。
- **基岩版兼容性回退机制**: 当基岩版玩家触发了未定义的特定动作（如 `bedrock-right-click`）时，插件将自动尝试回退执行对应的通用动作（如 `right-click`）。

### 改进
- **更新检测算法优化**: 增强了对非纯数字版本号（如 `v1.4.0-beta.2`）的解析健壮性。
- **CI/CD 补全**: 完善了 Modrinth 发布流程，支持版本列表现已包含 1.13 至 1.21.1 的所有正式版。

### 修复
- 修复了 GitHub 更新源配置中 owner 信息错误的问题。
- 删除了冗余的内部监听器，解决了潜在的事件冲突问题。

---

## v1.4.0-beta.1 (2025-12-28)

### 核心特性
- **模块化配置重构**: 引入了 `Default_config/` 机制，支持多文件独立配置物品。
- **实时配置文件重载**: 基于 Java `WatchService` 实现，修改配置即刻生效，无需手动输入重载指令。
- **次数性消耗系统**: 支持多种消耗模式（固定、概率、随机区间、概率区间）。
- **线程安全增强**: 核心配置读取引入 `ReentrantReadWriteLock` 读写锁。
- **配置平滑迁移**: 自动识别旧版本配置并迁移至新结构，同时保留备份。

### 改进
- 优化了 Floodgate 基岩版玩家的检测与交互逻辑。
- 移除了所有不必要的 Emoji 字符以符合纯净文档规范。
- 增加了详细的迁移与操作日志。

### 修复
- 修复了在极端高并发下重载配置可能导致的物品读取异常。
- 修复了延迟执行命令在特定环境下可能不执行的问题。
