# 简介

TpaGui 是一个为 Minecraft 服务器设计的 TPA 请求图形化界面插件。它本身不实现传送逻辑，而是作为 GUI 层调用你现有 TPA 插件（EssentialsX、HuskHomes 等）的命令，通过直观的界面替代繁琐的手动输入。

## 核心特性

- **多平台支持**：适配 Paper 1.21+（及其分支），可选接入 Velocity 代理实现跨服玩家列表同步。
- **双端优化**：
  - **Java 版**：箱子菜单（Chest GUI）展示在线玩家头颅，1.21.6+ 收到请求时可弹出原生 Dialog。
  - **基岩版（Geyser）**：自动识别并使用原生表单（Form）界面，传送请求以弹窗形式接受/拒绝。
- **返回按钮**：双端通用，材质与执行命令可配置（如 Java 执行 `/cd`、基岩执行 `/gmenu` 返回主菜单）。
- **隐私友好**：自动隐藏隐身玩家，兼容 SuperVanish。
- **高度自定义**：所有界面文本支持多语言（简中/繁中/英文）与颜色代码，TPA 相关命令全部可配置。
- **智能更新检测**：支持启动时与周期性检查，及时向管理员提醒新版本。

## 为什么选择 TpaGui？

传统的 TPA 插件通常需要玩家记忆复杂的命令（如 `/tpa [玩家名]`）。TpaGui 将其转化为直观的操作：
1. 输入 `/tpagui`。
2. 在界面中找到想要传送的玩家。
3. **左键点击**：请求传送到该玩家。
4. **右键点击**：请求该玩家传送到自己。

对于基岩版玩家，插件会自动推送一个带有"接受/拒绝"按钮的表单；1.21.6+ 的 Java 玩家则可收到原生 Dialog 请求提示（未安装数据包时自动降级为聊天消息），极大提升了跨端玩家的游戏体验。
