# 简介

TpaGui 是一个为 Minecraft 服务器设计的 TPA 请求图形化界面插件。它旨在简化玩家之间的传送请求操作，通过直观的 GUI 界面替代传统的繁琐命令。

## 核心特性

- **多平台支持**：完美适配 Paper、Folia 和 Velocity 环境。
- **双端优化**：
  - **Java 版**：提供基于箱子菜单（Chest GUI）的界面，显示在线玩家头颅。
  - **基岩版（Geyser）**：自动识别并提供原生的基岩版表单（Form）界面，支持传送请求弹窗提醒。
- **高度自定义**：支持完全自定义所有界面文本、命令别名及颜色代码。
- **智能更新检测**：内置语义化版本检查逻辑，及时提醒插件更新。
- **国际化支持**：支持多语言日志输出及配置。

## 为什么选择 TpaGui？

传统的 TPA 插件通常需要玩家记忆复杂的命令（如 `/tpa [玩家名]`）。TpaGui 将其转化为直观的操作：
1. 输入 `/tpagui`。
2. 在界面中找到想要传送的玩家。
3. **左键点击**：请求传送到该玩家。
4. **右键点击**：请求该玩家传送到自己。

对于基岩版玩家，插件会自动推送一个带有“接受/拒绝”按钮的对话框，极大提升了跨端玩家的游戏体验。
