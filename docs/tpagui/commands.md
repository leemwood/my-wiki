# 命令与权限

TpaGui 的命令设计非常简洁，主要围绕一个核心命令展开。

## 指令列表

### 玩家指令

| 指令 | 描述 | 别名 |
| :--- | :--- | :--- |
| `/tpagui` | 打开传送请求主界面 | `/tpag`, `/tgui` |

### 控制台

在控制台执行 `/tpagui` 会输出当前在线玩家列表（自动隐藏隐身玩家；Velocity 模式下显示全服玩家），便于不依赖其他插件快速查看。

## 权限节点

| 权限名 | 描述 | 默认拥有者 |
| :--- | :--- | :--- |
| `tpagui.use` | 允许使用 `/tpagui` 命令 | 所有玩家 |
| `tpagui.admin` | 接收插件更新通知 | 管理员 (OP) |

---

:::tip 提示
如果你的服务器使用了权限插件（如 LuckPerms），建议检查默认权限组是否已包含 `tpagui.use`。
:::
