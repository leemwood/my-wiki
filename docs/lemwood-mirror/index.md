# 柠枺镜像 (Lemwood Mirror)

柠枺镜像 (Lemwood Mirror) 是一个自动化的启动器镜像系统，旨在自动从 GitHub 获取指定项目（如 FCL, ZL, ZL2）的最新 Release，并同步至本地服务器提供高速下载。

## ✨ 核心特性

- 🤖 **全自动同步**: 每 10 分钟自动检查 GitHub 更新并下载资产。
- 🚀 **并发下载**: 支持多任务并发下载，内置断点续传逻辑。
- 📊 **详尽统计**: 记录访问量、下载量、地理位置分布及趋势图表。
- 🖥️ **文件浏览**: 提供直观的 Web 端文件浏览与管理界面。
- 🔌 **标准 API**: 提供稳定的 RESTful API 供第三方服务集成。
- 🛡️ **加速下载**: 支持配置资源下载代理（如 Xget）以绕过网络限制。
