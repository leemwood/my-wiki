# Doubledoor 介绍

Doubledoor 是一款专为 Minecraft 木门设计的轻量级双开门插件。它能够自动检测并同步相邻且方向合法的木门状态，极大地提升了玩家的交互体验。

## 项目链接

- **GitHub**: [RunicWonders/Doubledoor](https://github.com/RunicWonders/Doubledoor)
- **问题反馈**: [Issues](https://github.com/RunicWonders/Doubledoor/issues)
- **最新下载**: [Releases](https://github.com/RunicWonders/Doubledoor/releases)

## 主要功能

- **智能同步**: 只需点击一扇门，另一扇门就会自动跟随开启或关闭。
- **材质兼容**: 支持不同木材种类的门组成双开门（可选）。
- **红石联动**: 支持红石信号触发双开（可选）。
- **潜行保护**: 潜行时默认不触发双开，方便玩家进行精细化方块放置或操作。

## 支持版本

- Minecraft 1.13 及以上版本。
- 兼容 Spigot, Paper, Purpur 等主流服务器核心。
