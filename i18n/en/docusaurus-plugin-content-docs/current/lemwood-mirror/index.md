# Lemwood Mirror (柠枺镜像)

Lemwood Mirror (柠枺镜像) is an automated launcher mirroring system designed to automatically fetch the latest releases from GitHub projects (such as FCL, ZL, ZL2) and sync them to a local server for high-speed downloads.

## ✨ Key Features

- 🤖 **Auto-Sync**: Automatically checks GitHub for updates and downloads assets every 10 minutes.
- 🚀 **Concurrent Downloads**: Supports multi-task concurrent downloads with built-in resume logic.
- 📊 **Detailed Statistics**: Tracks visits, downloads, geographic distribution, and trend charts.
- 🖥️ **File Browser**: Provides an intuitive Web interface for file browsing and management.
- 🔌 **Standard API**: Offers stable RESTful API for third-party service integration.
- 🛡️ **Accelerated Download**: Supports configuring download proxies (like Xget) to bypass network restrictions.
