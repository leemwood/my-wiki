# Logshare

Logshare is a Minecraft log sharing and analysis platform, rebuilt from mclo.gs, providing more stable and faster log upload and sharing services.

## ✨ Key Features

- 🚀 **Fast Upload**: Support multiple ways to upload log files
- 🔗 **Permanent Links**: Generate short links for easy sharing
- 📊 **Syntax Highlighting**: Support Minecraft log syntax highlighting
- 📱 **Responsive Design**: Perfectly adapts to all devices
- 🔌 **Built-in Integration**: Already integrated into FCL and ZL2 launchers
- 🇨🇳 **China Optimized**: Fast access and low latency for users in China

## 📝 About the Project

Logshare is developed by **Qichu** for both frontend and backend, hosted on Tencent Cloud server in Hong Kong. This project provides built-in log upload functionality for FCL and ZL2 launchers, making it easy for players to quickly share game logs.
