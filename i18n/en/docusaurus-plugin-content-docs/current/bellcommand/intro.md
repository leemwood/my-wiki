## **Important Note**
The source code for this plugin is provided by cursor-Claude 3.5; the author only provided ideas and direction.  
Please **consider carefully** before installing this plugin! (Backup your world if necessary)

## Core Requirements
- Java 21 or higher.
- Spigot or its forks, supporting Paper 1.13 - 1.21.

## Download
You can download the latest version (v1.4.0-beta.1) from:
- [Modrinth](https://modrinth.com/plugin/bellcommand)
- [GitHub Releases](https://github.com/ning-g-mo/BellCommand/releases)

## Installation
Place the `bellcommand-1.4.0-beta.1.jar` in your `plugins` folder and restart the server.

## Success
If you see this in the console:
```shell
[xx:xx:xx INFO]: [BellCommand] Enabling BellCommand v1.4.0-beta.1
[xx:xx:xx INFO]: [BellCommand] §aFloodgate detected, Bedrock support enabled
[xx:xx:xx INFO]: [BellCommand] §6[BellCommand] Version: v1.4.0-beta.1
```
Congratulations, it's working!
