# v1.4.0-beta.1

The first Beta release for the v1.4.0 series, aggregating all major updates from Alpha versions.

## 🚀 Core Updates
- **Config Overhaul**: Modular multi-folder architecture.
- **Consumables**: Support for various consumption logics.
- **Hot-Reload**: Real-time sync via `WatchService`.
- **Stability**: Implementation of `ReentrantReadWriteLock`.
- **Automation**: Deep integration with Modrinth release pipeline.

## 🛠️ Technical Improvements
- Full UTF-8 encoding support.
- Compiled with JDK 21.
- Optimized Floodgate player interaction detection.
