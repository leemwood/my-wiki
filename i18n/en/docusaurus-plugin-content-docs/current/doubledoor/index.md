# Introduction to Doubledoor

Doubledoor is a lightweight plugin designed specifically for wooden doors in Minecraft. It automatically detects and synchronizes adjacent, legally oriented wooden doors, greatly enhancing the player's interaction experience.

## Project Links

- **GitHub**: [RunicWonders/Doubledoor](https://github.com/RunicWonders/Doubledoor)
- **Issue Tracker**: [Issues](https://github.com/RunicWonders/Doubledoor/issues)
- **Downloads**: [Releases](https://github.com/RunicWonders/Doubledoor/releases)

## Key Features

- **Smart Sync**: Simply click one door, and the other will automatically follow to open or close.
- **Material Compatibility**: Supports different types of wooden doors forming a double door (optional).
- **Redstone Integration**: Supports redstone signals triggering double doors (optional).
- **Sneak Protection**: By default, it doesn't trigger double doors while sneaking, making it easier for players to perform precision block placement or operations.

## Supported Versions

- Minecraft 1.13 and above.
- Compatible with Spigot, Paper, Purpur, and other mainstream server cores.
